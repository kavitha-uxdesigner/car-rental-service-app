
# Car Rental Service App 🚗

## Project Overview
A mobile-first UI/UX design project focused on simplifying the car rental booking experience.

## Problem Statement
Users may find it difficult to compare rental vehicles and complete bookings through complicated booking flows.

## Design Goals
- Simplify vehicle discovery and selection.
- Improve the booking experience.
- Create a clear and user-friendly interface.

## Tools Used
- Figma
- Wireframing
- Prototyping
- UI/UX Design
